Questão 1: Interseção e Otimização Gráfica

# I. Pontos de interseção das retas (encontrando x e y):
- Reta 1: 6x1 + 4x2 = 24 -> Pontos nos eixos (0, 6) e (4, 0)
- Reta 2: x1 + 2x2 = 6 -> Pontos nos eixos (0, 3) e (6, 0)
- Reta 3: -x1 + x2 = 1 -> Pontos nos eixos (0, 1) e (-1, 0)
- Reta 4: x2 = 2 -> Reta horizontal

# II. Conjunto de Soluções Básicas factíveis (cálculo vértices):
- A (origem) = (0, 0)
- B (eixo y com R3): x1 = 0 => x2 = 1 => vértice B = (0, 1)
- C (intersecção R3 e R4): x2 = 2 ; -x1 + x2 = 1 => -x1 + 2 = 1 => x1 = 1 => vértice C = (1, 2)
- D (intersecção R4 e R2): x2 = 2 ; x1 + 2x2 = 6 => x1 + 4 = 6 => x1 = 2 => vértice D = (2, 2)
- E (intersecção R2 e R1): x1 + 2x2 = 6 => x1 = 6 - 2x2 -> substituindo:
  6(6 - 2x2) + 4x2 = 24
  36 - 12x2 + 4x2 = 24
  -8x2 = -12 => x2 = 1.5
  logo vértice E: x1 = 6 - 2(1.5) = 3 => vértice E = (3, 1.5)
- F (R1 no eixo x): Ponto em x2 = 0 => vértice F = (4, 0)
- Conjunto SBF: S = {(0, 0), (0, 1), (1, 2), (2, 2), (3, 1.5), (4, 0)}

# III. Testando para solução ótima (máx z = x1 + 2x2):

Questão 4: Método do M-Grande

# I. Adicionando variáveis artificiais e Função Objetivo (minimização):
- 3x1 + 2x2 - 4x3 + a1 = 10
- x1 - x2 + 3x3 + a2 = 60
- Z = 2x1 + 2x2 - 5x3 + M a1 + M a2

# II. Agora zerar o M das variáveis básicas:
- Isolar a1 e a2 e substituir em Z:
  a1 = 10 - 3x1 - 2x2 + 4x3
  a2 = 60 - x1 + x2 - 3x3
- Substituindo:
  Z = 2x1 + 2x2 - 5x3 + M(10 - 3x1 - 2x2 + 4x3) + M(60 - x1 + x2 - 3x3)
  Z = (2 - 4M)x1 + (2 - M)x2 + (-5 + M)x3 + 70M

[/tabela]
